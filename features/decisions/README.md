# Feature — Décisions

**Responsabilité :** transformer analyses et prédictions en recommandations concrètes : que faire, et pourquoi.

## Périmètre

- Priorisation des actions.
- Justification à partir des faits (anomalies, tendances, prévisions).
- Formulation actionnable pour une PME.

## Hors périmètre

- Calcul brut des indicateurs.
- Rédaction du rapport complet (`rapports`).

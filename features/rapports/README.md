# Feature — Rapports

**Responsabilité :** produire des rapports exploitables (ce qui s’est passé, ce qui risque d’arriver, ce qu’il faut retenir).

## Périmètre

- Composition d’un livrable (texte + chiffres + éventuelles visualisations).
- Export / génération d’un rapport final (`backend/` + lecture `frontend/`).

## Hors périmètre

- Dialogue interactif (`chatbot`).
- Recommandations d’actions structurées (`decisions`).

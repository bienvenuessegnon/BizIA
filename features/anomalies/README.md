# Feature — Anomalies

**Responsabilité :** détecter les écarts, valeurs aberrantes et signaux inhabituels dans les données structurées.

## Périmètre

- Règles et / ou modèles de détection.
- Qualification d’une anomalie (sévérité, série concernée).
- Alerte consommable par rapports, chatbot et décisions.

## Hors périmètre

- Structuration des données.
- Recommandation d’action (`decisions`).

# Feature — Analyse automatique

**Responsabilité :** analyser les données structurées (tendances, variations, corrélations, performances, KPI, évolutions) sans que l’utilisateur construise chaque analyse à la main.

## Périmètre

- Indicateurs clés.
- Variations et corrélations.
- Synthèse d’insights pour le dashboard et le chatbot.

## Hors périmètre

- Détection d’anomalies dédiée (`anomalies`).
- Prévisions (`predictions`).
- Rendu graphique (`visualisations`).

## Couches

- Backend : calculs (Pandas / ML).
- Frontend : affichage des insights et KPI.
